## Shodan ##

O Shodan é um mecanismo de busca que “escaneia” a internet e indexa informações como:

IPs de servidores
Portas abertas
Serviços rodando (HTTP, FTP, SSH, etc.)
Banners de sistemas
Tecnologias usada
